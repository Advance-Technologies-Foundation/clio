# Presentation branch — do not merge

This branch exists only to host a slide deck at a stable path so it can be opened
from any clone. It carries no code and is not intended for `master`.

| File | What it is |
|---|---|
| `eng-94583-guidance-externalization.html` | Deck for clio contributors on why MCP guidance moved to the `clio-knowledge` repository, how delivery works, and what changes in day-to-day work. |

The deck is a single self-contained file: no external fonts, scripts, styles or
images, so opening it directly from disk works offline. Navigate with the arrow
keys, `Space`, or the dots at the bottom. It follows the viewer's light/dark
system theme.

The deck body is in Ukrainian because that is the language it will be presented
in. It is deliberately kept off `master`, where the English-only rule applies.
