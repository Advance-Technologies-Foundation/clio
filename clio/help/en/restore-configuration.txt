NAME
    restore-configuration - Restore configuration from last backup

DESCRIPTION
    Restores Creatio configuration from the latest available backup package.

    The command prints the installation log written by the restore and exits
    with 1 when the service does not report success. The service message for a
    failed restore is generic, so the reason is in the installation log. The
    request is sent once: a repeated restore after a failed one reports
    success while the database structure stays in the newer state.

SYNOPSIS
    clio restore-configuration [OPTIONS]

OPTIONS
    -d
        Also install the data bound to the packages in the backup. Data is
        rolled back with or without this flag

    -f
        Restore configuration without SQL backward-compatibility check

    -e, --Environment <ENVIRONMENT_NAME>
        Target environment name

EXAMPLES
    clio restore-configuration -e dev
        Restore configuration from backup on the dev environment

    clio restore-configuration -d -f -e dev
        Restore configuration with relaxed safety checks
