COMMAND TYPE
    Skill management commands

NAME
    update-toolkit - Update the Creatio AI App Development Toolkit for all detected coding agents (alias: update-skill)

DESCRIPTION
    update-toolkit refreshes the Creatio AI App Development Toolkit skill for every
    detected coding agent, using each agent's native update mechanism. No Python
    runtime is required.

    Before updating an agent, update-toolkit compares the toolkit commit that agent
    recorded as installed with the commit published on the toolkit's release branch
    (one `git ls-remote` call). An agent that already has the published commit is
    reported as up to date and left untouched. Claude Code and Codex record their
    installed commit; Cursor and Copilot do not, so they are always updated. When
    either commit cannot be determined (git not on PATH, no network, unreadable
    agent metadata), the agent is updated as if there were no check. Use --force to
    reinstall regardless.

    Agents that need an update are refreshed with their own mechanism: Claude Code
    via `claude plugin update`; Codex, Cursor, and Copilot against the latest source.
    Use --target to limit the operation to a single agent.

    The default source is the public toolkit marketplace. Use --repo to override it
    (a marketplace git URL for claude/codex/copilot; a local path or git URL for the
    cursor file-copy). A --repo override always updates, because there is no
    published release commit to compare against.

    update-toolkit is idempotent and reports a per-agent outcome. A detected agent
    whose CLI is not on PATH is skipped with a warning and does not fail the command.
    Only one toolkit install, update, or removal runs at a time on a machine; a second
    one started meanwhile fails immediately and changes nothing (if the lock file cannot be
    created at all, operations run unguarded instead).

SYNOPSIS
    clio update-toolkit [options]

OPTIONS
    --target                            Optional agent to limit to:
                                        claude | codex | cursor | copilot.
                                        When omitted, all detected agents are updated.

    --repo                              Optional source override. Marketplace git URL
                                        for claude/codex/copilot; local path or git URL
                                        for cursor. Defaults to the public toolkit marketplace.

    --force                             Reinstall even when an agent already has the
                                        latest release. Also restores the agent
                                        configuration an update repairs (for example
                                        the clio MCP server entry). Default: false.

EXAMPLES
    Update every detected agent that is behind the latest release:
        clio update-toolkit

    Reinstall the toolkit for Codex even if it is current:
        clio update-toolkit --target codex --force

    Update only Cursor from a local checkout:
        clio update-toolkit --target cursor --repo C:\Repos\creatio-ai-app-development-toolkit

NOTES
    The scheduled toolkit auto-update (see `clio autoupdate`) runs this command as
    a detached background process, so it never delays the command that started it.

    An agent reported as up to date also skips the configuration repairs its update
    would perform. Run with --force, or run install-toolkit, to restore them.

    --scope and --skill have been removed. update-toolkit operates on the whole
    toolkit bundle across agents (use --target to narrow).
