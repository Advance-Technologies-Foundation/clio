NAME
    link-core-src - Link core source code to environment for development

USAGE
    clio link-core-src [<EnvironmentName>] [options]

DESCRIPTION
    Link core source code to environment for development.

    In NetCore mode, Kestrel endpoint hosts are constrained to localhost and the
    HTTP port is taken from the registered environment URI. Existing HTTPS endpoint
    settings are preserved and also constrained to localhost.

ALIASES
    lcs

EXAMPLES
    clio link-core-src [<EnvironmentName>] [options]

ARGUMENTS
    EnvironmentName
        Application name

OPTIONS
    --core-path <VALUE>
        Path to Creatio core source directory. Required.
    --mode <VALUE>
        Creatio mode: NetCore (Terrasoft.WebHost) or NetFramework
        (Terrasoft.WebApp.Loader). Default: NetCore.

        Alias for --login

        Alias for --workspace-pathes
