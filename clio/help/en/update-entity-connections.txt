COMMAND TYPE
    Development commands

NAME
    update-entity-connections - Set an object's Connections to a full ordered list of lookup columns
    (writes the EntityConnections add-on)

DESCRIPTION
    Sets the "Connections" of an object (entity schema) - the ordered lookup columns of the Object
    designer "Connections" node, shown as fields by the Freedom UI crt.Connections page component - to
    the full desired ordered list given in --connections.

    A column left out of the list is removed; an empty list removes every connection. Only lookup
    columns of the object (own or inherited) are accepted. An unknown column, a column that is not a
    lookup, or a column listed twice fails before anything is written.

    The command writes the EntityConnections add-on of --package-name exactly as the Object designer
    does: only the difference from the parent package layers is stored. It then resets the client
    script cache and reads the state back. When the list already matches, nothing is written and the
    response reports changed=false.

    The write is refused when the effective list cannot be read with the add-on applied - when
    EntityConnectionsService is not available, or when its list does not reflect the add-on content
    (the UseConnectionsComponent feature may be off). A column removed by another package layer cannot
    be brought back from this package; the response then carries a warning.

SYNOPSIS
    clio update-entity-connections -e ENVIRONMENT --entity-schema-name NAME --package-name NAME
        --connections COLUMN[,COLUMN...]

OPTIONS
    -e, --environment NAME
        Registered Creatio environment to target.

    --entity-schema-name NAME
        Required. Object (entity schema) name, e.g. 'Account'.

    --package-name NAME
        Required. Package whose EntityConnections add-on layer is written, e.g. 'Custom'.

    --connections COLUMN[,COLUMN...]
        Required. Full desired ordered list of lookup column names, comma-separated, e.g.
        'Owner,PrimaryContact'. An empty string ("") removes every connection.

    -u, --uri URI / -l, --login LOGIN / -p, --password PASSWORD
        Direct connection fallback when no registered environment is used.

EXAMPLES
    # Put PrimaryContact first and keep Owner after it.
    clio update-entity-connections -e dev --entity-schema-name Account --package-name Custom --connections PrimaryContact,Owner

    # Remove every connection of the object in this package.
    clio update-entity-connections -e dev --entity-schema-name Account --package-name Custom --connections ""

NOTES
    Aliases: entity-connections-set, set-entity-connections.

    Read the current list with get-entity-connections first: the list you pass replaces the current
    one, so a column you do not repeat is removed.

    Lookup-only is a clio rule that matches the Object designer; the platform itself accepts any column.

    Requires the CanManageSolution operation (the add-on save checks it).
