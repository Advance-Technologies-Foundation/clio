COMMAND TYPE
    Remote commands

NAME
    call-service - Call a Creatio service endpoint

SYNOPSIS
    clio call-service [OPTIONS]

DESCRIPTION
    Calls a Creatio service endpoint. The HTTP method defaults to POST and can
    be set to GET, POST, DELETE, PATCH, or PUT. Request data can be read from
    a file or supplied inline with --body.

OPTIONS
    -m, --method              HTTP method. Defaults to POST.
    -f, --input               Request file.
    -b, --body                Request body JSON.
    -d, --destination         Destination file for the response.
    --service-path            Route service path.
    -v, --variables           Variables to replace in the request body.
    --timeout                 Request timeout in milliseconds. Defaults to 60000
                              for call-service.
    --maintainer              Maintainer name. Long form only for this command,
                              because -m is taken by --method here.
    --silent                  Do not print the response body.

    -e, --environment <ENVIRONMENT>
        Registered environment to call. When omitted, clio uses the active
        environment.

    Environment options (can be used instead of -e):
        -u, --uri <URI>
            Application URI

        -l, --login <LOGIN>
            User login

        -p, --password <PASSWORD>
            User password

        --client-id <ID>
            OAuth client id

        --client-secret <SECRET>
            OAuth client secret

        --auth-app-uri <URI>
            OAuth app URI

EXAMPLES
    clio call-service -e dev --service-path "odata/Contact(<id>)" \
        --method PATCH --body '{"Name":"Updated"}'

    clio call-service -e dev --service-path "odata/Contact(<id>)" \
        --method PUT --input contact.json
