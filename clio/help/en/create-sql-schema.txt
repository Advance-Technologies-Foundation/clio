COMMAND TYPE
    Development commands

NAME
    create-sql-schema - Create an empty native package SQL script

ALIASES
    sql-schema-create

SYNOPSIS
    clio create-sql-schema --schema-name NAME --package-name PACKAGE [OPTIONS]

DESCRIPTION
    Saves an empty SQL script directly to Creatio through
    SqlScriptSchemaDesignerService/SaveSchema. Does not execute SQL or write local
    workspace files. Requires configuration-management access and an editable package.
    Names start with a letter and contain only letters, digits or underscores.
    Duplicate or ambiguous names are refused. Name validation reports errors together.

OPTIONS
    --schema-name       Required unique script name
    --package-name      Required destination package
    --db-engine-type    0 MSSql, 1 Oracle, 2 PostgreSql; default: detect target engine
    --install-type      0 before package, 1 after package (default),
                        2 after schema data, 3 uninstall app
    -e, --environment   Registered environment
    -u, --uri           Direct application URL
    -l, --login         Direct login
    -p, --password      Direct password

    Legacy --caption, --description and --caption-culture are recognized but
    nonempty values are rejected because package SQL scripts have no such fields.

EXAMPLES
    clio create-sql-schema --schema-name UsrCleanup --package-name Custom -e dev
    clio update-sql-schema --schema-name UsrCleanup --body-file cleanup.sql -e dev
    clio get-sql-schema --schema-name UsrCleanup -e dev
    clio install-sql-schema --schema-name UsrCleanup -e dev

NOTES
    If engine detection is unavailable, supply --db-engine-type explicitly.
    Empty or HTML responses name the failed operation and URL; HTTP status is unknown.
    An unusable save response is verified against this attempt's generated UId.
    SQL save and execution requests are not automatically replayed.
