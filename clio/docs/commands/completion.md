# completion

Print the shell tab-completion script for a shell.


## Usage

```bash
clio completion <Shell> [options]
```

## Description

Print the shell tab-completion script for a shell.

## Examples

```bash
clio completion <Shell> [options]
```

## Arguments

```bash
Shell
    Target shell: bash, zsh, powershell, fish (pwsh and ps are accepted for
    powershell). Required.
```
