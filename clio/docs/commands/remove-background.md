# remove-background

## Command Type

    Branding commands

## Name

remove-background - remove the background of a custom Creatio theme

## Description

Removes a custom theme's own background, so its users see the site background again. Requires Creatio
10.2.96 or later.

## Synopsis

```bash
clio remove-background --theme <theme-id> -e <environment>
```

`--theme` is the theme id from [`list-themes`](list-themes.md).
