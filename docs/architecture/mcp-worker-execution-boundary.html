04 · Нова межа виконання

Parent маршрутизує. Кожен worker виконує рівно один MCP-виклик

05 / 08
①

Створити worker

Parent запускає короткоживучий clio mcp-server для одного виклику.

②

Передати MCP-контракт

Аргументи, результат, поступ і запити до клієнта проходять крізь parent.

③

Убити після бюджету

Parent не просить зупинитися — він завершує процес ззовні.

④

Прибрати спільний замок

У worker-процесів немає спільної сесії чи пам’яті, яку треба захищати.

Убитому процесу не потрібно «погоджуватися» на таймаут.Нова межа
