**What is true** — On the retained Creatio 10.1.585.0 FSM lab, importing an
updated partial user task and calling `GenerateSchemasSources` succeeded while
the package's `Autogenerated/Src` companion still contained its original class.
A package-only compilation executed that old body. Full native compilation
refreshed the companion and the process returned the new 12,000-character output.

**Why it is this way** — `SchemaManager.SaveSchemaSources` persists generated
sources in the database. Materializing compilation files is a separate native
workspace build step. `GenerateSchemasSources` takes a bare JSON array of schema
UIds, not an object containing `schemaUIds`.

**What breaks if you ignore it** — Successful metadata import or source generation
alone does not prove that the runtime executes the new task implementation.
Verify the generated properties and actual process output after compilation.
